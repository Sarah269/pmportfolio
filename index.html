My Work

Cross‑functional change with 75% fail rate

Problem:

Secured network implementation failing on most server builds due to poor coordination between technical teams; growing backlog and costly rework.

Problem Solution:

Coordinated all teams to execute changes together on the same night. Established blameless problem‑solving, comprehensive design reviews, and aligned testing protocols.

Results:

Success rate jumped from 25% to over 75%, rework nearly eliminated. Engineers voluntarily trained other teams on the process, spreading the improvement across the organization.

18‑month stalled datacenter migration

Project Description:

Critical communication servers installed in the wrong datacenter location; project abandoned for 12 months with no clear path forward.

Project Solution:

Assigned a dedicated Technical PM for the physical move, worked with engineering to re‑integrate server provisioning into the standard fulfillment workflow.

Project Results:

Delivered in 3 months after 12‑month stall. Production deployment 30 days later, obsolescence risk eliminated, team recognized with Excellence award.
